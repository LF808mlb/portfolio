# Lesley's Portfolio

This responsive portfolio project is made up of five main building blocks: a header menu at the top with clickable links to jump to different parts of the page, a big hero section that introduces myself and two action buttons, a projects showcase with photos and details of my TripleTen projects, a skills grid listing my tech abilities grouped into categories, and a contact area at the bottom so people can get in touch.
